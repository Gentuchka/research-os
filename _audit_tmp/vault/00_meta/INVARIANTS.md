# Research invariants

1. Knowledge is immutable — append, archive, supersede, link only.
2. Every object has provenance.
3. Every new node must increase information.
4. Mathematical graph stays acyclic (equivalence via classes, not cycles).
5. Facts and opinions are stored separately.
6. Every relation has a defined type — no generic "related."
7. Every iteration must increase knowledge (including failed attempts).
8. Every claim references evidence or is marked speculative.
9. History is permanent.
